## ☁️ Featured Cloud & DevOps Projects

### 💰 [AWS Finance Billing Automation](https://github.com/iamlwinkoko/aws-finance-billing-automation)

Serverless AWS workflow that automates monthly invoice delivery to Finance.

**Architecture & Tools**

`AWS Lambda` · `EventBridge Scheduler` · `AWS Invoicing API` · `Cost Explorer` · `Amazon S3` · `Amazon SES` · `Terraform` · `Python`

**What it does**

* Retrieves the previous month's AWS invoice
* Stores the official invoice PDF in Amazon S3
* Generates a Cost Explorer summary
* Emails the invoice automatically to Finance
* Deploys the infrastructure using Terraform
